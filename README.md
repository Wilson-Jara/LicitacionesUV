# Sistema de Gestión de Licitaciones Universitarias (Frontend)

Este software es la interfaz cliente diseñada en **React + Vite** para agilizar, centralizar y optimizar la creación de licitaciones dentro de la universidad, proporcionando además herramientas interactivas para evaluar y elegir la mejor oferta de los proveedores.

---

## 1. Requisitos Previos del Entorno

Asegúrate de contar con las siguientes herramientas instaladas antes de inicializar el proyecto [13]:
- **Runtime:** Node.js (Versión v18 LTS o superior recomendada)
- **Gestor de paquetes:** npm (Versión v9 o superior)

---
